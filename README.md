# Tanvir Azad — Cinematic Portfolio

React + Vite + TypeScript + Tailwind CSS portfolio adapted from the supplied Prisma cinematic direction.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to Netlify

- Build command: `npm run build`
- Publish directory: `dist`

## Stack

- React 18
- TypeScript
- Tailwind CSS 3
- Framer Motion
- Lucide React
